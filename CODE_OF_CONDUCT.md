# Code of conduct

OmaStore follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and patient, assume good intent, criticize ideas and
code rather than people, and accept that maintainers make the final call on
what goes into the project. Harassment, insults and personal attacks are not
tolerated in issues, pull requests or any other project space.

## Reporting

Report unacceptable behavior privately to the maintainer,
[@KitsuneSemCalda](https://github.com/KitsuneSemCalda), through a
[private security advisory](https://github.com/KitsuneSemCalda/OmaStore/security/advisories/new)
if nothing else fits. Reports are handled confidentially. The maintainer may
edit or remove comments, and warn or ban participants, following the
Covenant's enforcement guidelines.
