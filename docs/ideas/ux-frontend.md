# Interface ideas

Open items for the frontend. Search, grid navigation, `/`, `Esc`, `Ctrl+R`,
the checksum badge, the empty state, the rate limit message and the theme are
done (Phase 8); release notes and the "Open" button are done (Phase 18);
`h/j/k/l`, `i`, `u`, the `?` list, `omastore://` links,
pagination and the pt_BR translation are done.

- **Translation, what is left:** the interface is translated (`frontend/i18n`,
  pt_BR first). The details the daemon appends to errors (`%1` in the
  messages) and the CLI are still in English; known error codes are already
  translated by the interface.
